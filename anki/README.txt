Bunka Japanese Studio — Anki files

Cards: 302 total (166 vocabulary cards + 136 lesson/grammar cards).

APKG: import/open bunka_japanese_core.apkg in Anki. Cards are grouped into subdecks for vocabulary, grammar, fashion Japanese and Bunka admission.
TSV: In Anki Desktop use File → Import, select the TSV, choose the Basic note type and tab separator if it is not detected automatically. The TSV includes HTML and a tags column.

Japanese text is UTF-8. The card examples are instructional samples; review context and meaning as you learn.
