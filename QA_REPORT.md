# QA Report — Bunka Japanese Studio (hotfix)

Дата: 27 октября 2026 года.

## Исправления

- Инициализация независимых частей интерфейса разделена на изолированные этапы. Сбой одного необязательного модуля больше не должен прерывать запуск списка уроков, текущего урока, карты Genki или прогресса.
- Добавлена диагностика JavaScript-ошибок и необработанных Promise-ошибок в консоль.
- При ошибке инициализации отдельного модуля интерфейс показывает сообщение, а остальные модули продолжают запускаться.
- Удалён дублирующийся вызов сохранения прогресса при оценке кандзи.
- Сохранены исходный `index.html`, все данные курса, словарь, кандзи, CSS, Anki-экспорт и сопроводительные материалы.

Поэтому здесь подтверждены синтаксис, целостность архива и структура данных; не утверждается, что был пройден полный интерактивный браузерный тест. После публикации на GitHub Pages проверь запуск урока и кнопки теста.
