# QA Report — Bunka Japanese Studio

Дата: 27 октября 2026 года.

## Автоматические проверки, выполненные в текущей сборке

- `node --check script.js` — успешно.
- `node --check course-data.js` — успешно.
- JSON внутри `course-data.js` успешно разобран Node/Python-проверкой.
- Курс содержит 183 учебные записи, 23 главы и 24 тестовых вопроса.
- Словарь: 1 700 уникальных записей по паре «японское написание + чтение».
- Кандзи: 1 000 уникальных символов, включая все 438 прежних, и 317 знаков official Genki.
- Anki TSV создан из текущей базы; ожидаемый состав — 1 700 слов + 183 учебные записи + 1 000 кандзи = 2 883 карточки.

## Ограничения контроля качества

- 905 словарных записей получены OCR и требуют сверки; английские исходные глоссы обозначены в интерфейсе.
- 195 кандзи помечены для проверки и исключены из оценочного теста.
- Полный лингвистический аудит всех OCR-записей не завершён.
- Не заявляется полное распознавание текста всех страниц PDF.
- Поле рукописной практики не распознаёт правильность написания автоматически.
- Проверку UI в реальном браузере следует отличать от статических проверок JavaScript и данных; в этом отчёте приводятся только реально выполненные проверки.
