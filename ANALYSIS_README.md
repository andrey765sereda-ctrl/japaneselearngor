# Как читать отчёты курса

- `TEXTBOOK_ANALYSIS.md` фиксирует структуру, полученную из содержания предоставленных Genki I/II, и отделяет её от авторского материала приложения.
- `COURSE_MAP.md` показывает маршрут из 23 глав и что включено в каждый модуль.
- `GRAMMAR_COVERAGE_23_LESSONS.csv` — список отдельных грамматических целей и кратких объяснений по главам.
- `OFFICIAL_GENKI_KANJI_317.csv` — целевые кандзи издателя с привязкой к урокам.
- `weekly_plan_104_weeks.csv` — подробный маршрут с заданиями на каждую неделю.
- `COVERAGE_REPORT.md` содержит проверяемые количества и прямые ограничения, особенно по словарю и постраничной расшифровке.
- `QA_REPORT.md` фиксирует статические проверки.

Принцип: структура и целевые грамматические пункты сверяются с источниками, а пояснения, примеры, мини-тексты и вопросы создаются заново. Не считать оригинальные учебники полностью перенесёнными в приложение.
