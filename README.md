# Bunka Japanese Studio

Статический сайт для самостоятельного изучения японского языка и подготовки к подаче документов в Bunka Fashion College. Работает без платных API, серверной базы данных и установки Node.js.

## Что внутри

- 183 урока общего каталога (включая 23 подробных модуля Genki I/II).
- 122 грамматические цели, объяснённые на русском, с оригинальными примерами, чтением и переводом.
- 23 оригинальных коротких текста для чтения, по главе на модуль.
- 69 вопросов для мини-тестов с мгновенной обратной связью.
- 1 700 записей словаря (905 OCR-кандидатов помечены для проверки), 1 000 кандзи (317 целевых Genki; 195 записей кандзи требуют сверки).
- Локальный прогресс, интерактивный двухлетний план и подробный `weekly_plan_104_weeks.csv` (104 строки с конкретными еженедельными задачами).
- Экспорт всех текущих карточек в Anki-совместимый TSV.
- Тёмная тема, четыре основных раздела: Курс, Слова и кандзи, Практика, Прогресс.

## Запуск Windows 11

1. Распакуй ZIP в обычную папку.
2. Запусти `start-local.bat`.
3. В браузере откроется `http://localhost:8765`. Если Python 3 не установлен, можно попробовать открыть `index.html` напрямую.

## GitHub Pages

Загрузи содержимое папки в корень репозитория и в настройках репозитория открой **Settings → Pages**. В источниках публикации выбери ветку и корневую папку (`/`). Сайт не требует сборки.

## Anki

Для колоды, соответствующей текущей базе, используй `anki/bunka_japanese_full.tsv` или кнопку «Скачать все карточки» внутри сайта. В Anki выбери тип заметки Basic и разделитель Tab. Файл `bunka_japanese_core.apkg` — компактная стартовая колода, не полный экспорт всех текущих записей.

## Важная точность

Сайт покрывает последовательность 23 глав, 122 грамматические цели и все 317 целевых кандзи из официального списка Genki. Локальный каталог сейчас содержит 1 700 уникальных записей: 905 OCR-кандидатов явно помечены для проверки, 335 слов являются дополнением, а прежние записи сохранены. Это размер каталога, а не подтверждение точного и безошибочного совпадения со всем издательским списком. Каталог 1 000 кандзи сохраняет все 438 прежних знаков; 317 целевых Genki помечены отдельно, 195 неполных/извлечённых записей кандзи имеют флаг проверки. Модули содержат собственные примеры и чтения, а не копии оригинальных диалогов. См. `COVERAGE_REPORT.md`, `DATA_COVERAGE_REPORT.md`, `TEXTBOOK_ANALYSIS.md` и `SOURCES.md`.

## Основные файлы

- `index.html` — структура.
- `style.css` — оформление.
- `script.js` — интерактивность.
- `course-data.js` — каталог, словарь, кандзи и авторские модули.
- `genki-course.js` — точка доступа к данным подробного курса.
- `GRAMMAR_COVERAGE_23_LESSONS.csv` — 122 цели грамматики.
- `OFFICIAL_GENKI_KANJI_317.csv` — список 317 целевых кандзи.
