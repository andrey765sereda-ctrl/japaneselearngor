# Bunka Japanese Studio — курс Genki I + II

Самостоятельный статический сайт для изучения японского языка на Windows 11 и подготовки к поступлению в Bunka Fashion College. Он включает 23 авторских учебных модуля, привязанных к грамматической программе всех глав Genki I и Genki II, карточки, тесты, список официальных кандзи по главам, дополнительные слова и отслеживание прогресса.

## Запуск

1. Распакуй архив.
2. Запусти `start-local.bat` (нужен Python 3) **или** открой `index.html` напрямую.
3. Для локального сервера открой `http://localhost:8765`.

У сайта нет серверной части, регистрации, платного API или обязательных зависимостей. Прогресс записывается локально в браузере; перед очисткой браузерных данных экспортируй резервную копию в разделе «Прогресс».

## Что входит

- `index.html`, `style.css`, `script.js` — интерфейс и логика сайта.
- `course-data.js` — 183 урока, 303 словарные записи, 438 карточек кандзи (включая расширение), вопросы и карта 23 глав.
- 23 отдельные оригинальные главы Genki I–II с целями, грамматическими пояснениями, примерами, заданиями и тематическим мини-тестом.
- `OFFICIAL_GENKI_KANJI_317.csv` — список из 317 знаков/позиций официального списка с номером урока и данными карточки сайта.
- `GRAMMAR_COVERAGE_23_LESSONS.csv` — карта грамматических целей и оригинальных объяснений по всем главам.
- `anki/bunka_japanese_full.tsv` — актуальный TSV для импорта в Anki.
- В разделе «Слова и кандзи» есть ссылка на внешний словарный указатель Genki Study Resources для справочной работы с лексикой; сам внешний список не копируется в дистрибутив.
- `COURSE_MAP.md`, `COVERAGE_REPORT.md`, `TEXTBOOK_ANALYSIS.md`, `SOURCES.md`, `QA_REPORT.md` — карта покрытия и ограничения.

## Публикация на GitHub Pages

Загрузи все файлы из распакованной папки в корень репозитория. На GitHub открой **Settings → Pages → Deploy from a branch**, выбери `main` и папку `/(root)`.

## Важное ограничение по учебникам

Это **не дословная расшифровка** двух защищённых авторским правом учебников. Сайт содержит собственные объяснения и упражнения, а список грамматических целей сверяется с официальным syllabus третьего издания. Он не воспроизводит полностью исходные диалоги, тексты чтения, аудиосценарии, задания рабочих тетрадей и весь издательский словарь. Для этих материалов используй собственные экземпляры Genki и официальные ресурсы издателя. См. `COVERAGE_REPORT.md`.
