# Bunka Japanese Studio

Статический интерактивный сайт для изучения японского языка и подготовки к поступлению в Bunka Fashion College. Неофициальный учебный проект.

## Содержание курса

| Модуль | Уроки |
|---|---:|
| Кандзи, кана и произношение | 8 |
| Основа A1 / JLPT N5 | 34 |
| JLPT N4 | 20 |
| JLPT N3 | 20 |
| JLPT N2 | 23 |
| Японский для моды и конструирования | 16 |
| Подготовка к поступлению в Bunka | 15 |
| **Всего** | **136** |

В комплект также входят 166 слов, 24 вопроса для смешанных тестов и Anki-колода из 302 карточек (166 слов + 136 карточек по урокам).

## Публикация на GitHub Pages

1. Создай новый репозиторий на GitHub, например `bunka-japanese`.
2. Загрузи в корень репозитория файлы `index.html`, `style.css`, `script.js`, `course-data.js`, `README.md`, `SOURCES.md`, `.nojekyll` и папку `anki/` целиком.
3. Открой **Settings → Pages**.
4. В **Build and deployment** выбери **Deploy from a branch**, ветку `main`, папку `/(root)` и нажми **Save**.
5. После публикации сайт будет доступен по адресу вида `https://ТВОЙ-ЛОГИН.github.io/bunka-japanese/`.

Это обычный статический сайт — сервер, база данных и ключи API не нужны.

## Что работает

- поиск по названию/содержанию уроков и фильтры по модулю и статусу;
- 136 уроков с правилом, примером, чтением, переводом и собственным заданием;
- озвучивание японских примеров через синтез речи браузера, если он поддерживается;
- смешанные тесты по 10 вопросов с пояснением ответов;
- локальный список карточек с повторением по простым интервалам;
- импортируемая колода Anki `.apkg` и TSV-экспорт в UTF-8;
- сохранение прогресса, черновиков и оценок в браузере;
- экспорт/импорт резервной копии прогресса в JSON;
- мобильная верстка и светлая/тёмная тема.

## Anki

- `anki/bunka_japanese_core.apkg` — готовая колода с подколодами Vocabulary, Grammar, Fashion Japanese и Bunka Admission.
- `anki/bunka_japanese_core.tsv` — текстовая колода для импорта/редактирования.
- `anki/README.txt` — короткие инструкции.

В Anki Desktop открой `.apkg` или выбери **File → Import** для TSV. При импорте TSV используй тип заметки Basic, разделитель Tab и включённый HTML в полях, если Anki не определит это автоматически. Anki-колода не синхронизируется с сайтом автоматически: файлы импортируются в Anki отдельно.

## Ограничения текущей версии

- Прогресс сайта хранится в `localStorage` конкретного браузера и не синхронизируется между устройствами.
- Встроенное повторение на сайте — простая локальная схема. Для ежедневного долгосрочного повторения используй планировщик Anki.
- Проверка собственного японского предложения пока основана на сравнении с образцом, а не на автоматическом лингвистическом анализе.
- Программа охватывает основные темы и даёт большую учебную карту; для реального уровня N2 также нужны регулярное чтение, аудирование, большое количество лексики и пробные тесты.
- Перед поступлением перепроверь актуальные требования и сроки на официальном сайте Bunka Fashion College: они могут меняться.

## Локальный запуск

Открой `index.html` в браузере. Если браузер ограничивает хранение данных на `file://`, запусти простой локальный статический сервер или используй опубликованную страницу GitHub Pages.
