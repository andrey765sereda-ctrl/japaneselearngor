# Карта курса Genki I + Genki II

Последовательность названий взята из официальной программы; пояснения, учебные примеры и задания сайта написаны самостоятельно.

## Genki I — уроки 1–12

1. **New Friends / あたらしいともだち** — именные предложения, вопросы с か, の.
2. **Shopping / かいもの** — указательные слова, место, принадлежность, も, отрицание, ね／よ.
3. **Making a Date / デートの約束** — группы глаголов, ます-форма, частицы, время, частота, приглашения.
4. **The First Date / 初めてのデート** — наличие, местоположение, прошедшее время, длительность, перечисление.
5. **A Trip to Okinawa / 沖縄旅行** — прилагательные, предпочтения, счётчики, предложения.
6. **A Day in Robert's Life / ロバートさんの一日** — て-форма, просьбы, разрешения/запреты, причины, помощь.
7. **Family Picture / 家族の写真** — ている, описание людей, соединение прилагательных, цель движения, счёт людей.
8. **Barbecue / バーベキュー** — краткие формы, разговорная речь, цитаты, предпочтения в действиях, が, 何か／何も.
9. **Kabuki / かぶき** — прошедшие краткие формы, определение существительных, もう／まだ, причины.
10. **Winter Vacation Plans / 冬休みの予定** — сравнения, намерения, изменения состояния, транспорт, неопределённые места.
11. **After the Vacation / 休みのあと** — желания, опыт, неполные перечни, たり.
12. **Feeling Ill / 病気** — объяснения, чрезмерность, советы, причины, обязанность и осторожные вопросы.

## Genki II — уроки 13–23

13. **Looking for a Part-time Job / アルバイト探し** — потенциальная форма, несколько причин, впечатления по виду, てみる, なら, частота.
14. **Valentine's Day / バレンタインデー** — желания, вероятность, направление подарка/услуги, советы, 数量＋も／しか.
15. **A Trip to Nagano / 長野旅行** — волевая форма, намерения, подготовка заранее, придаточное определение.
16. **Lost and Found / 忘れ物** — просьбы об услуге, чрезвычайно вежливая просьба, пожелания, 時, извинение.
17. **Grumble and Gossip / ぐちとうわさ話** — пересказ услышанного, условие たら, отсутствие необходимости, みたい, порядок событий.
18. **John's Part-time Job / ジョンさんのアルバイト** — переходные/непереходные пары, てしまう, закономерное と, одновременность, сожаление.
19. **Meeting the Boss / 出迎え** — уважительные глаголы, благодарность, облегчение, ожидания.
20. **Mary Goes Shopping / メアリーさんの買い物** — скромная речь, встроенные вопросы, названия через という, лёгкость/сложность.
21. **Burglar / どろぼう** — пассив, подготовленное состояние, период времени, изменение объекта, желаемое действие другого человека.
22. **Education in Japan / 日本の教育** — каузатив, наставление, условия, контраст, подобие.
23. **Good-bye / 別れ** — каузатив-пассив, уступка, решения и привычки, временная граница, способы действия.
